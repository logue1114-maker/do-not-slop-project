# Sources, rights and publication boundaries

## Included material

The package contains the exact model-produced original TIDELINE implementations, project-authored brief/guide/reviews, original generated environmental art, and actual cloud-browser captures of those fictional project UIs. Source and runtime bytes were not visually retouched for publication. `shared/provenance.json` is a public provenance copy that removes two execution-local machine paths; its generation prompt, tool, date, dimensions and original-image SHA-256 remain intact.

The bundled Open Sans regular, semibold and condensed-bold font binaries retain their supplied Apache-2.0 license and copyright notice in `shared/fonts/`. That font license applies to the fonts; it does not establish a new license for unrelated project materials. The repository's previously undecided reuse-license choice remains unchanged.

All third-party screenshot bytes, downloaded article HTML, thumbnails and other private reference-folder files are excluded. Input-manifest reference hashes document what was privately supplied; they grant no redistribution rights. The only relocated reference-related input is the project-authored textual guidance, published as `guidance.txt` with its exact frozen hash.

Publication adds this scoped case and one root README entry. It does not change the repository-wide inventory, license, earlier evidence, existing implementation or unrelated navigation. No user-account data, credentials, private reference media, internal notes or delivery URLs are included.
