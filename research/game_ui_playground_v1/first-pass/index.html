These are independently authored proposals with synthetic data. Preset comparisons use the same scene and records; they are not experimental runs or approved designs.

Keep the state honest

  • Selecting gear never equips it.
  • Reviewing a purchase never spends coins.
  • Cancel and Back preserve committed state.
  • Confirm resolves one pending purchase once.
  • Edge arrows report direction, not exact position.

Keep the game usable

  • Use shape and text as well as color.
  • Keep actions clear of map and item overlays.
  • Return focus to the control that opened a view.
  • Freeze cooldown while paused or in another station.
  • Use Escape to return one level.
