The following primary sources clarify scope, rather than prescribe this design’s dimensions:

- [WCAG 2.2 target size minimum](https://www.w3.org/TR/WCAG22/#target-size-minimum): AA uses 24×24 CSS px with exceptions, including spacing. The [enhanced criterion](https://www.w3.org/TR/WCAG22/#target-size-enhanced) uses 44×44 at AAA, also with exceptions. Our proposed 44/46/56px controls do not establish conformance.
- [GOV.UK Back link](https://design-system.service.gov.uk/components/back-link/): the scoped service pattern returns to the previous page in its last-seen state. This informs the retained-context proposal; it is not a blanket site-navigation standard.
- [Xbox XAG 112 navigation](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112): platform-specific input/navigation guidance. Browser Tab remains ordinary DOM order; controller menu wrapping is not copied.
