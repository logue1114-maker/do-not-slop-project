# Do Not Slop Project · UI copy

UI 문장을 짧게 만드는 것보다 정보·상태·행동을 정확히 보존하는 교정 패키지입니다. 범용 환영 문구, 과장된 효익, 보이는 조작의 재설명, 모호한 버튼, 오류의 말투와 복구, 확인 내용, 빈 화면, 진행 상태, 거절 문구의 9개 패턴을 다룹니다.

## 읽기

1. [한국어 매뉴얼](manual_ko.md): 공개 실무자 비판 6개 사례 → 자체 교정안 → 9개 운영 규칙 → 한국어 적용 → 검수
2. [기계가 읽는 규칙](rules.json): 입력/출력 계약, 보호 조건, 적용·반례 시험
3. [원문 근거](sources.json): 공식 지침·저자 의견·사례 보고와 각 한계
4. [전후 HTML](copy_examples.html): 파일을 브라우저로 직접 열 수 있는 독립형 예시. 같은 상태와 행동의 문구 비교

## 검증

Python 3와 Node.js가 있으면 이 폴더에서 `python3 validate.py`로 정적/JavaScript 단위 검사를 다시 실행할 수 있습니다. 외부 라이브러리를 설치하거나 네트워크에 연결하지 않습니다.

공개 소스의 `validate.py`는 현재 실행 시각과 파일 해시를 새 `validation.json`에 기록합니다. 정적 검사와 JavaScript 단위 검사는 실제 렌더링·모바일·확대·키보드·스크린리더·사용성 향상을 검증하지 않습니다. 이 검증기에서 해당 게이트는 `not_run`으로 유지합니다.

교육용 HTML은 실제 계정, 업로드, 발행, 이메일 구독, 결제와 연결되지 않습니다. 숫자와 데이터는 자체 제작 시나리오의 고정 조건입니다. 원문 글·제3자 화면을 재배포하지 않고, 출처별 짧은 인용과 링크만 포함했습니다. 공개 사용성 향상 수치는 없습니다.
