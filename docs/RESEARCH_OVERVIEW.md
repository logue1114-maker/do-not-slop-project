# Understand the reports

[Project overview](../README.md) · [Start using the rules](START_HERE.md) · [Full research index](RESEARCH_INDEX.md)

The project turns concrete interface problems into task-specific rules, applies them in implementations, and keeps evidence for review. A manual explains a proposed rule; an example shows an implementation; a test report records what was actually checked. Their evidence levels differ.

### TIDELINE R2: title and entry flow

[R2 case](../research/title_entry_prompt_trial_r2/README.md) · [comparison/source](../research/title_entry_prompt_trial_r2/index.html) · [common brief](../research/title_entry_prompt_trial_r2/shared/brief.txt) · [added guidance](../research/title_entry_prompt_trial_r2/guidance.txt)

Original producer outputs are retained without hand-retouching. **Partial improvement:** B improves portrait composition/readability; A has stronger desktop title impact, a filled Start action and radio-looking exclusive choices. This pair does not establish an overall winner, universal effectiveness, measured usability or user design approval.
