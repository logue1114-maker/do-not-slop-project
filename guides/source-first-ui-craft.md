# Source-first craft: observe, propose, render, test

Use a source to identify a concrete design relationship, then implement it with original content and verify the actual target. Keep four records distinct: **SOURCE_VISIBLE** (permitted source pixels actually seen), **TARGET_PROPOSED** (authored layout/material choices), **TARGET_RENDERED** (actual target captures), and **BEHAVIOR_TESTED** (performed inputs and outcomes).

## A bounded game-title case

The [North Marsh title revision](../research/north_marsh_title_arrival_v3/README.md) uses a large connected destination silhouette, quiet identity/action region, coherent type/glyph scale and controlled contact edges. It includes a large same-data before/after pair, separate full after frames and native state crops. Earlier candidate 2.0.4 is rejected history. Positive feedback on this title does not approve every earlier example or establish finished AAA quality.

| [Forza work, William Emery](https://williamemery.artstation.com/projects/lD1oL5) | Pixel inspection blocked by HTTP403; link only | No implementation observation or third-game-inspection claim |

An additional restricted reference board was unavailable. No bypass was attempted and no board identifier is published. Source stills do not prove transitions, pressed behavior, usability, current-build details or physical controller support. External AAA screenshots remain links; only original target artwork is included.

Construction should address silhouette, proportion, material/light, type, glyph alignment, layout and state together. Counts of controls, compliance with a spacing token or darker recoloring cannot establish craft. Verify actual press pixels and cancel restoration rather than treating a state log as a visual result. Use native input semantics and report physical/native tests separately.

The target's 200% authored text model has usable actions in the bounded checks but crowds the artwork. That concern remains open; true native text scaling and full AAA craft are not claimed. A reference principle is a proposal for a target, not an empirical A/B result.
