# RPG 장비

아래 교정은 자체 제안이다. 출처는 좁은 원리/역사적 제작 사례의 배경 근거이며, 예시 숫자나 개선 효과를 입증하지 않는다. 화면에 증상이 없으면 적용하지 않는다. 타사 artwork·폰트·이미지 bytes를 복사하지 않는다.

범위: 선택한 장비와 현재 장비를 비교하고 장착/취소/게임 복귀. 전투·지도·전체 RPG 재설계는 지원 밖이다.

- 확인할 실패: 같은 위치의 현재/후보 능력치가 다른 축에 있고, 장착 버튼과 설정이 같은 강조를 갖거나, 버튼/슬롯/패널의 재료·광원이 기존 장면과 이유 없이 다르다
- 구체 명령: 현재/후보의 같은 능력치를 한 행 기준선에 맞춘다. 차이는 수치와 부호/라벨로 함께 남긴다. 후보 이름·제약·장착 동작을 같은 상세 패널에 묶고, 설정은 기존 시스템 위치에 둔다. 장면의 외곽/재료/광원/아이콘 획을 먼저 기록한 뒤 공유 component tokens를 맞춘다
- 예시: 픽셀 장면에서 후보 장비 버튼만 유리 pill이라면 ‘후보 장착 버튼의 외곽을 현재 슬롯과 같은 픽셀 단위 rim로 바꾸고, 눌림은 내부 면만 이동; 슬롯 hitbox·라벨 baseline·장착 수치를 고정’처럼 지시한다. 종이/혼합 매체가 의도된 경우 이 수정은 거절한다
- 상태: focus와 장착됨을 다른 표시로 둔다. 사용 불가에 부족 조건을 남긴다. hover/press는 바깥 hitbox나 형제 배치를 흔들지 않는다
- 보존/시험: 같은 current/candidate ID, 수치, 비용, 선택 상태와 게임 camera. 장착 후 수치, 취소 후 원상태, 장비창 닫기 후 focus/플레이 복귀를 시험한다
- 근거: AS:S23은 입력/정보 대안 배경, GCTRL2:S01은 2018 WIP widget 가족, GCTRL2:S04/S05는 초기 SF concept의 공통 조형과 서사별 재료 선택. 모두 이 RPG의 성공률이나 현행 제품 상태를 입증하지 않는다
- 연결: AS:V01–V04, AS:AS18, AS:AS22의 재작성/선택 적용. 이번 package는 원문 전체를 묶지 않는다
