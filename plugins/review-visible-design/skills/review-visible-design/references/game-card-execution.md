# 카드 실행

아래 교정은 자체 제안이다. 출처는 좁은 원리/역사적 제작 사례의 배경 근거이며, 예시 숫자나 개선 효과를 입증하지 않는다. 화면에 증상이 없으면 적용하지 않는다. 타사 artwork·폰트·이미지 bytes를 복사하지 않는다.

범위: 손패에서 카드 선택 → 대상 선택 → 기존 계약의 실행/취소. 덱 편집·경제·전체 전투 설계는 지원 밖이다.

- 확인할 실패: 비용은 tooltip에만 있고 현재 자원과 떨어져 있다. 손패 겹침이 카드 이름/비용을 가린다. focus·선택·대상 확정·실행 완료가 모두 같은 glow다. 카드 사용과 턴 종료가 같은 의미처럼 보인다
- 구체 명령: 카드의 항상 보이는 상단에 이름/비용을 두고 선택 상세에 효과·현재 자원·허용 대상/부족 이유를 함께 놓는다. 선택 카드는 기존 손패 경계 안에서 읽히도록 reveal하되 다른 카드의 핵심 정보를 가리지 않는다. 주실행과 턴 종료를 분리하고 기존 confirm/auto-execute 의미를 보존한다
- 조형: 종이 카드라면 face/ink/선택 rim 한 가족을 유지한다. UI를 ‘카드’라는 이유만으로 3D 종이로 재해석하지 않는다. 아이콘 획과 라벨 inset은 실제 렌더 크기에서 검사한다
- 상태: focus = 탐색 중인 대상, selected = 사용 대기 카드, legal target = 허용 대상, executed = 자원/효과 결과. 의미가 다른 상태를 색 하나로 합치지 않는다
- 보존/시험: 같은 hand order/card IDs/cost/effect/resource/target/turn. 선택 취소 시 자원 불변, 실행 1회에서 비용 1회 차감, 불법 대상에서 미실행, 턴 종료 시 상태 보존 여부를 시험한다
- 근거: AS:S23은 접근성/정보 대안의 배경 근거. GCTRL2:S03은 2020 Factorio의 확인/취소 분리 역사 사례로 카드 동작의 직접 근거가 아니다. 즉시 실행을 새 확인 버튼으로 바꾸는 것은 별도 흐름 변경이다
- 연결: AS:V01–V04, AS:AS22, AS:AS23. 고정 card 게임 recipe의 효과는 미검증
