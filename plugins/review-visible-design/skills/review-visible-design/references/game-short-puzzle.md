# 짧은 퍼즐

아래 교정은 자체 제안이다. 출처는 좁은 원리/역사적 제작 사례의 배경 근거이며, 예시 숫자나 개선 효과를 입증하지 않는다. 화면에 증상이 없으면 적용하지 않는다. 타사 artwork·폰트·이미지 bytes를 복사하지 않는다.

범위: 한 보드의 첫 행동, 일시정지/재시작, 선택/일치/실패 피드백. 모든 casual 게임이나 monetization 화면을 지원한다고 광고하지 않는다.

- 확인할 실패: 큰 환영 카드와 규칙 문단이 보드를 밀어내고, 이동/목표/도움이 같은 버튼 장식이다. closed/flipped/matched/focus가 색 변화 외에는 구별되지 않는다
- 구체 명령: 첫 행동에 필요한 목표/조작 한 줄을 보드 근처에 두고 긴 규칙은 재열 수 있는 도움으로 옮긴다. 목표·이동 수는 읽기전용 표시, 도움/일시정지는 작은 같은 가족의 system controls, 실제 board targets는 안정된 hitbox로 둔다. 문구 제거 후 고정 hero 높이도 해제한다
- 조형 예시: 만화 종이 아트가 기존 방향인 경우에만 공통 ink outline/짧은 lower shadow를 panel과 조작에 쓴다. GCTRL2:S07의 Tintin artwork를 복제하지 않는다. 다른 아트에서는 해당 장면 가족을 유지한다
- 상태: match 결과는 형태/상태 라벨도 남기고, focus가 flip commit과 다르면 분리한다. reduced motion에서도 결과 상태를 알 수 있게 한다
- 보존/시험: 같은 seed/board/목표/이동 수/초기 열린 타일. 첫 행동, 같은 match/fail milestone, 재시작 seed 계약, pause/return와 focus를 시험한다. 학습 안내를 지웠다면 초심자의 첫 성공을 별도 관찰한다
- 근거: GCTRL2:S07은 원저자의 만화 정체성/퍼즐 UI portfolio, AS:S23은 학습/입력 대안 배경. 제안의 치수·보드 우선 정도·실제 사용성을 입증하지 않는다
- 연결: AS:V01–V04, AS:V06–V08, AS:AS23
