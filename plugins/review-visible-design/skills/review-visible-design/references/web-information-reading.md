# 정보 열람

아래는 원문을 복제한 템플릿이 아니라 자체 교정 제안이다. 동일 콘텐츠 시안과 실제 동작 검증을 구분한다. 전면적 색/서체/아이콘/사이드바 금지는 없다.

범위: 하나의 문서/짧은 정보 허브를 읽고 절/검색 결과를 찾고 돌아오기. 현재 정책·의료/법률 사실 검증은 별도 작업이다.

- 확인할 실패: 클릭 불가 형식 아이콘이 버튼처럼 보인다. 제목/목차/본문의 축이 어긋나고, 포괄적 홍보 hero가 독자의 필요한 답보다 먼저 읽힌다. 문구 삭제 후 빈 거터가 남았다
- 구체 명령: 형식이 제목만으로 분명하면 장식 아이콘을 제거하고 제목·목차·본문 시작선을 재정렬한다. 짧은 6절 안내면 제목 아래 모든 절을 보이는 목록으로 검토한다. 장문이면 현재 위치가 보이는 지속 목차를 유지할 수 있다. 질문을 답하는 제목으로 바꾸고 유효 날짜/조건/대체 경로를 가까이 둔다
- 문구 ledger: 제목이 이미 말하는 ‘아래에서 정보를 확인’은 삭제 후보. 자격·비용·제출 서류·위험·오류 복구·유효 날짜·출처는 보호 정보다. 오래된 정보 제거는 콘텐츠 책임자가 확인해야 한다
- 보존/시험: 같은 document/sections/body/links/current section/reader position와 실제 정보 범위. 절 이동/검색/0건/브라우저 뒤로/읽던 위치/인쇄를 요청 범위에서 시험한다. 긴 제목과 좁은 화면에서 목차/본문을 다시 본다
- 근거: WCV2:S05는 2013 GDS 형식 아이콘의 오인/제거와 재배치 기록. WCV2:S06은 2022 정보 허브의 내용 우선순위 변경을 다룬 역사 사례이며 현행 보건 안내가 아니다. 원문 전후는 통제된 동일-content 실험이 아니다
- 연결: AS:V05, AS:V07–V09. 아이콘·사이드바 전체 제거 규칙으로 일반화하지 않는다
