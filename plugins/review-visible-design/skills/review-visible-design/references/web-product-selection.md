# 상품 선택과 담기

아래는 원문을 복제한 템플릿이 아니라 자체 교정 제안이다. 동일 콘텐츠 시안과 실제 동작 검증을 구분한다. 전면적 색/서체/아이콘/사이드바 금지는 없다.

범위: 상품 특징/옵션/가격을 판단하고 cart에 담기·수량 변경·삭제. 주소/결제정보 입력이나 결제 실행은 지원 밖이다.

- 확인할 실패: 추상 hero와 장점 카드가 실제 상품/옵션/총액을 밀어낸다. 모든 정보가 같은 무게다. 옵션 변경 상태와 담기 완료가 구별되지 않거나 배송 조건을 설명문과 함께 지웠다
- 구체 명령: 상품을 판단할 실물 이미지/특징, 옵션, 옵션별 가격/재고, 수량과 담기 결과를 하나의 결정 영역에 둔다. 비교가 속성 대조이면 공통 행 축을, 시각 차이 판단이면 이미지 중심 구조를 고른다. ‘목록을 클릭해 보세요’ 같은 중복문을 제거하고 남은 고정 빈 공간도 줄인다
- 문구 보존: SKU/옵션 이름·단가/할인 조건·수량·배송비/미확정 표시·합계·재고·환불/수령 조건 중 실제 결정에 필요한 항목을 남긴다. 결제를 단순히 만든다는 이유로 가격 약정을 숨기지 않는다
- 보존/시험: 같은 SKU/options/quantity/prices/currency/cart/state. option 변경과 담기 후 어떤 상품이 몇 개 들어갔는지, 수량 변경/삭제의 합계와 빈 cart 상태를 시험한다. 변동 세금/배송은 확정 금액으로 꾸미지 않는다
- 근거: AS:S13은 작업별 표 선택, AS:S18은 명확한 UI 문구의 배경. WCV2:S01은 완료 구역을 요약하는 Shopify의 결제 개편 설명으로만 참조하며 cart 구현·화면 실측의 직접 증거가 아니다
- 연결: AS:V05–V09. 결제 검수나 상점 성공률을 이 분기의 통과로 보고하지 않는다
