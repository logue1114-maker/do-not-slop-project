# 수업과 확인 문제

아래는 원문을 복제한 템플릿이 아니라 자체 교정 제안이다. 동일 콘텐츠 시안과 실제 동작 검증을 구분한다. 전면적 색/서체/아이콘/사이드바 금지는 없다.

범위: 한 과정의 현재 수업 위치/완료 상태와 간단한 확인 문제의 응답/피드백/재시도/수업 복귀. 계정·채점 정책·전체 LMS나 영상 player 구현은 지원 밖이다.

- 확인할 실패: 전역 메뉴와 과정/수업 색인이 한 트리에 섞였다. 환영 카드/통계가 수업 또는 문제보다 크게 보인다. 현재/완료, 선택 답/정답/오답이 같은 강조다
- 구체 명령: 탐색 범위가 실제로 다르면 전역 위치와 과정 탐색을 분리한다. 과정 색인은 현재 수업과 완료 상태를 남기고, 보조 drawer는 닫혀도 재열 수 있게 한다. 질문/응답을 주위계로, 진도를 보조로 둔다. 이미 화면이 말하는 안내 문장을 빼고 그 영역의 고정 높이도 제거한다
- 상태/문구: 선택 답과 채점 결과를 구분한다. 오답 피드백에 무엇을 다시 볼지와 재시도/수업 복귀를 남긴다. 오류와 학습 오답을 혼동하지 않는다. ‘짧게’ 하려고 목표/선수 지식/필수 조건을 지우지 않는다
- 보존/시험: 같은 course/lesson/question/options/correctness/attempt/progress와 initial state. 정답·오답·재시도, 중간 복귀/색인 재열기에서 현재 수업/스크롤/focus를 확인한다. 영상이 실제 입력에 없으면 player 동작을 통과했다고 쓰지 않는다
- 근거: WCV2:S02는 2021 Moodle prototype의 탐색 의도, WCV2:S03은 2022 출시 설명과 역사적 홍보 이미지의 좁은 범위. 이 패키지는 source CSS 크기·로그인 학습실·터치 동작을 검증하지 않았다. AS:S18은 문구 배경
- 연결: AS:V06–V09. 수업이 3개인 간단한 흐름에 다층 탐색을 새로 강제하지 않는다
